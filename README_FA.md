پروژه جامع پاکسازی، تحلیل آماری و **تحلیل اکتشافی داده‌ها (Exploratory Data Analysis - EDA)** بر روی دیتاست معروف مسافران کشتی تایتانیک از وب‌سایت کگل (Kaggle) جهت شناسایی عوامل اجتماعی و جمعیت‌شناختی مؤثر بر بقای مسافران در فاجعه دریایی ۱۹۱۲.

---

## نمای کلی پروژه

در ۱۵ آوریل ۱۹۱۲، کشتی اقیانوس‌پیمای تایتانیک در اولین سفر خود با کوه یخ برخورد کرد و غرق شد. از مجموع ۲۲۲۴ مسافر و خدمه حاضر در کشتی، بیش از ۱۵۰۰ نفر جان خود را از دست دادند.

این مخزن به بررسی و کشف الگوهای آماری پنهان در داده‌های مسافران می‌پردازد. این تحلیل با استفاده از زبان **پایتون (Python)** و کتابخانه‌های قدرتمند **Pandas**، **NumPy**، **Matplotlib** و **Seaborn** پیاده‌سازی شده و فرآیند کامل پیش‌پردازش داده‌ها، تحلیل همبستگی متغیرها و مصورسازی روابط را شامل می‌شود.

نکات برجسته:
- **پاکسازی سیستماتیک داده‌ها:** مدیریت و جایگزینی مقادیر گمشده (Missing Values) در متغیرهای سن (`Age`)، کابین (`Cabin`) و بندر سوارشدن (`Embarked`).
- **تحلیل روابط و همبستگی:** بررسی عمیق اثر طبقه اجتماعی مسافر (`Pclass`)، جنسیت (`Sex`)، قیمت بلیط (`Fare`) و همراهی اعضای خانواده (`SibSp` + `Parch`) بر شانس بقا.
- **داستان‌سرایی بصری (Visual Storytelling):** ترسیم نمودارهای توزیع آماری، هیت‌مپ‌های همبستگی، نمودارهای جعبه‌ای (Boxplot) و مقایسه درصدی نجات‌یافتگان.
- **تحلیل گام‌به‌گام و تکرارپذیر:** کدها به صورت مرتب در یک ژوپیتر نوت‌بوک تعاملی (`eda.ipynb`) به همراه توضیحات کامل مستند شده‌اند.

## فرهنگ متغیرهای دیتاست

دیتاست شامل سوابق ۸۹۱ مسافر و ۱۲ ویژگی است:

| متغیر | شرح و کاربرد | مقادیر و محدوده |
| :--- | :--- | :--- |
| `PassengerId` | شناسه اختصاصی مسافر | ۱ تا ۸۹۱ |
| `Survived` | وضعیت نجات | `0` = فوت‌شده، `1` = نجات‌یافته |
| `Pclass` | کلاس بلیط مسافر | `1` = درجه یک (مرفه)، `2` = درجه دو، `3` = درجه سه (عادی) |
| `Name` | نام کامل مسافر همراه با عنوان | رشته متنی |
| `Sex` | جنسیت | `male` (مرد)، `female` (زن) |
| `Age` | سن مسافر به سال | ۰.۴۲ تا ۸۰.۰ |
| `SibSp` | تعداد خواهر، برادر یا همسر حاضر در کشتی | ۰ تا ۸ |
| `Parch` | تعداد والدین یا فرزندان حاضر در کشتی | ۰ تا ۶ |
| `Ticket` | شماره شناسه بلیط | الفبایی-عددی |
| `Fare` | بهای پرداختی بلیط | ۰.۰۰ تا ۵۱۲.۳۳ دلار |
| `Cabin` | شماره کابین مسافر | الفبایی-عددی (دارای مقادیر گمشده زیاد) |
| `Embarked` | بندر محل سوار شدن | `C` = شربورگ، `Q` = کوئینزتاون، `S` = ساوت‌همپتون |

## یافته‌های کلیدی تحلیل

۱. **تأثیر سرنوشت‌ساز جنسیت («ابتدا زنان و کودکان»):** درصد نجات مسافران زن (حدود ۷۴٪) بسیار بالاتر از مسافران مرد (حدود ۱۹٪) بوده است.
۲. **شکاف طبقاتی و تأثیر ثروت:** بیش از ۶۲٪ مسافران کلاس یک نجات یافتند، در حالی که شانس بقای مسافران کلاس سه کمتر از ۲۵٪ بود.
۳. **تأثیر خانواده:** مسافرانی که همراه با خانواده‌های کم‌جمعیت (۱ تا ۳ نفر) سفر می‌کردند شانس بقای بالاتری نسبت به مسافران تنها یا خانواده‌های پرجمعیت داشتند.
۴. **توزیع سنی:** کودکان زیر ۱۰ سال در اولویت سوار شدن به قایق‌های نجات قرار گرفتند، در حالی که نرخ بقا در میان افراد سالخورده به شدت پایین بود.

### پیش‌نیازها

- پایتون نسخه ۳.۸ یا بالاتر
- ژوپیتر نوت‌بوک یا ژوپیترلب

### مراحل راه‌اندازی

۱. **کلون کردن مخزن:**
   ```bash
   git clone https://github.com/soheilabbasnia/titanic-eda.git
   cd titanic-eda
   ```

۲. **ایجاد و فعال‌سازی محیط مجازی:**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

۳. **نصب وابستگی‌ها:**
   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```

۴. **اجرای ژوپیتر نوت‌بوک:**
   ```bash
   jupyter notebook eda.ipynb
   ```
